# Agent 适配边界

本技能以审计提示词为核心。适配帮助执行智能体读取某个 Agent 的原生对话、usage、工具事件、
父子会话和时间信息；督查结论仍由执行智能体理解上下文后形成。

## 当前支持

原始证据取证当前支持 **Codex**。扩展其它 Agent 时，先研究它的会话谱系、工具结果、Token
字段、完成语义、超时语义和时间戳边界，再编写专用取证配方或适配器。

| 层次 | 当前实现 | 性质 |
| --- | --- | --- |
| Codex 对话发现、父子谱系与事件解释 | `SKILL.md` 与取证参考 | Agent 专用提示词 |
| Codex Token 与超时观察记录 | 子审计员依据原生证据填写 JSONL | Agent 专用判断 |
| Token 加总与比率 | `token_totals.py` | 通用轻量计算器 |
| 超时校验与描述统计 | `timeout_summary.py` | 通用轻量计算器 |

## 稳定结构

```text
Agent 原生对话、轨迹或 API
          ↓
专用取证配方（必要时才使用小型专用适配器）
          ↓
审计智能体的语义判断与标准化观察记录
          ↓
可选的通用轻量计算器
          ↓
审计智能体复核、解释并提出优化建议
```

执行智能体是链路的控制者：主动搜索可用信息，结合身份、时间线、状态变化与完整对话重建观察，
说明采用了直接读取、重建还是语境判断。工具只帮助提取和计算。

## 专用方法和工具

Agent 专用层负责：

- 会话发现、根对话与后代谱系；
- 原生调用、结果、完成、等待与超时语义；
- 输入、缓存输入、输出和推理用量字段；
- 时间戳、共同 cutoff、压缩、回滚与身份关联；
- 从原始载荷中进行隐私安全取证。

可以先写简洁的专用取证提示，也可以在机械提取有帮助时增加小型专用适配器。专用适配器把原生
事实转成标准化观察候选；跨对话结论、分布选择和优化建议继续由执行智能体完成。

为不同 Agent 保留独立取证配方或小型适配器，使各自语义清楚可调试。遇到一次性或异常轨迹时，
可以修改、裁剪或新写任务内工具；明确适用范围。稳定复现后，再决定是否沉淀为长期专用适配器
或通用能力。

## 通用工具

通用层只负责：

- 标准化字段的基础校验与重复 sample ID 拒绝；
- Token 向量加总、分母一致的比率重算；
- 固定 N 项超时目录覆盖检查；
- 简单分位数、结果计数和超时—运行时间描述性关系；
- 隐私安全的聚合输出。

把原生轨迹读取、专有工具语义、父子关系、时间关联和统计模型选择交给执行智能体及专用适配层；
通用工具接收普通 JSONL/JSON，使审计员可以用 shell、表格、Python、R 或其它数学工具灵活
组合。跨 Agent 比较先按 `agent` 分层，再根据测量口径决定如何比较。

## 扩展其它 Agent

1. 记录该 Agent 的原生会话、身份、完成、等待、超时和 Token 契约。
2. 用真实样本写一份最小取证配方，说明直接读取、重建和语境判断分别如何工作。
3. 让审计员输出现有 Token 或超时 JSONL，并保留精确的 `agent` 区分字段。
4. 用原生样本验证谱系、用量对账、时间关联、删失和隐私边界。
5. 在 `scripts/adapters/` 添加有助于该 Agent 取证的单一职责小型适配器。
6. Agent 无关的计算需求可以扩展通用计算器，任务特有逻辑也可以保留在当次审计工具中。
7. 完成上述证据后，才在本参考和技能元数据中标记该 Agent 受支持。

把直接读取、重建和语境判断的比例作为数据质量说明。完成原生测量口径验证后，再把该 Agent
列入当前支持范围。
